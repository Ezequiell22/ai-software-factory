# Example Java Project Plugin

Copy this directory to the target repository as `.ai/`.

Recommended target structure:

```text
your-java-repo/
├── .ai/
│   ├── project.yaml
│   ├── architecture.md
│   ├── conventions.md
│   ├── business-rules.md
│   ├── agents.yaml
│   └── mcps.yaml
├── src/
├── pom.xml
└── ...
```
